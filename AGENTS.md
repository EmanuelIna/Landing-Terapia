# Diretrizes do projeto

- Use `main` ou `secondary` para branches. Não use `codex` no nome de nenhuma branch, a menos que o usuário peça expressamente.
- Stack: Next.js App Router, React, TypeScript estrito, Tailwind CSS, Lucide e Radix.
- A identidade visual da Giovanna pertence exclusivamente a esta landing: creme, grafite, verde, areia, detalhes em rosa e CTAs verde-água.
- Use Fraunces nos títulos e Nunito no texto; preserve as fontes locais e suas licenças.
- Imagens devem usar `next/image`. Preserve os componentes modulares e o layout mobile-first.
- Mantenha os contatos da Giovanna em `src/components/therapy/config.ts`. Não substitua pelo contato do desenvolvedor.
- Não invente depoimentos, notas, credenciais ou resultados clínicos. Avaliações reais exigem autorização.
- Valide com `npm run build` antes de enviar alterações. Mantenha a versão independente e a integração no portfólio sincronizadas.
